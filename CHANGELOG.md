## v0.0.1 - 2026-11-29

### Added

- Authentication packages for passwords, JWTs, API keys, sessions, OIDC, DPoP, TOTP, and WebAuthn.
- Relationship-based authorization and `net/http` authentication middleware.
- In-memory and `database/sql` storage adapters, with conformance tests for custom stores.
- Redis adapters for session storage and JWT replay protection in the separate `redis/` module.
